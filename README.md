## 📝 Descrição do Projeto

O atual projeto define a aplicação web de um portfólio feito em **HTML** e **CSS** com base em um protótipo do Figma fornecido pelos professores do curso ***HTML e CSS:Trabalhando com responsividade e publicação de projetos*** (link nos créditos finais). <br>

O objetivo é o de aplicação prática dos conteúdos de responsividade no CSS com a abordagem mobile-friendly. Para isso, foi utilizado o Media Querry para definir quais estilizações de espaçamento seriam aplicadas se o dispositivo do usuário tivesse um width menor que o padrão, o qual poderia quebrar a aplicação. Outra inovação desse site é o uso de medidas relativas de espaçamento, não mais as absolutas. Isso permite que o layout fique responsivo a diferentes telas de dispostivos, como tablets e celulares. <br>

Portanto, através da possibilidade de se acessar o site também em dispositívos móveis, o projeto se torna acessível para mais pessoas, o que segue as práticas do mercado real de escalabilidade e produção web. <br>

## 🎯 Objetivos do Curso

- Saiba como tornar seu site responsivo para diferentes telas;
- Descubra o que é como usar a Media Query em seus projetos;
- Crie uma conta no GitHub para armazenar seu código na nuvem;
- Entenda a diferença de medidas absolutas e relativas;
- Publique seu projeto finalizado na web e mostre para todo o mundo. <br>
